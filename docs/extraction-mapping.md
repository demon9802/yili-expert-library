# 专家信息 → 五星制结构化评分 提取映射规范（v1，2026-08-10）

> 本文件定义「自由文本专家信息 → 5 项子维度结构化评分」的提取规则。
> 数据源：`专家资源库_69位信息待修复.xlsx`（单 sheet `专家资源库`，69 位专家，12 列）。
> 提取结果对齐 `js/app.js` 的 `DEFAULT_RATING_CONFIG` 子维度命名。
> 版本约定：本规范随提取脚本 `tools/extract_scores.py` 同步演进，改动须在此注明版本与日期。

## 一、数据源字段 → 子维度映射

| 子维度（app.js 命名） | 维度 | 主要来源列 | 辅助来源列 |
|---|---|---|---|
| 学历与学术背景 | professional | 学历 | 突出优势、资历资质（职称/荣誉头衔） |
| 行业资质与认证 | professional | 资历资质（认证/资格表述）、社会职务 | 突出优势、课程/案例 |
| 专业成果与经验 | professional | 突出优势（■ 要点）、履职资历、课程/案例 | 资历资质（项目/成果表述） |
| 社会荣誉与奖项 | influence | 资历资质（职称/荣誉头衔、荣誉/奖项表述）、社会职务 | 突出优势 |

## 二、资历资质 分段解析

`资历资质` 列由 `【xxx】` 标签分段，主要标签：
- `【职称/荣誉头衔】` → 职称、荣誉、头衔（院士/教授/研究员/各类人才称号）
- `【社会职务】` → 协会/学会/委员会任职、认证出题/培训专家、厂商认证讲师
- `【履职资历】` → 企业任职（CEO/总裁/副总裁/总监/CTO/院长/创始人）、曾任经历

提取时先按 `【标签】` 切分，再在对应分段内匹配关键词。

## 三、各子维度分档规则（1–5★）

> 状态标记：`missing`=字段空白或显式"未公开"；`vague`=有信息但笼统（如"认证讲师"无具体名称）；`clear`=有具体可判定信号。

### ① 学历与学术背景（来源：学历）
- 博士（含博士后） → **5★**（`clear`）；院校为清北/浙大/C9/QS前100/海外名校可保持 5★，普通院校博士 → 4★（暂不细分，首版统一 5★）
- 硕士 / MBA / EMBA / 研究生 → **4★**（`clear`）
- 本科 / 学士 → **3★**（`clear`）
- 大专 / 专科 → **2★**（`clear`）
- 空白 / 显式"未公开" → **2★**（`missing`，区别于本科的 3★）

### ② 行业资质与认证（来源：资历资质·认证表述、社会职务）
- 5★（`clear`）：国际公认高含金量——CFA / CPA（注册会计师）/ ACCA / FRM / PMP / 法律职业资格（律师）/ 华为 HCIE / 微软 MVP / 阿里/腾讯云 MVP / 国家级认证出题&培训专家（工信部/人社部人工智能相关）
- 4★（`clear`）：多领域国家级执业、单一国家级执业、厂商高级认证（华为/阿里/腾讯云认证讲师）、IEEE Senior Member 等技术会士
- 3★（`vague`）：仅"认证讲师""企业认证""行业认证""培训师"等笼统表述（有认证但无具体含金量信号）
- 2★（`missing`）：全字段无任认证/资格表述

### ③ 专业成果与经验（来源：突出优势 ■、履职资历、课程/案例）
- 5★（`clear`）：牵头/参与国标或行标、国家级重大专项、顶刊一作/通讯或高被引、创办国家地方联合工程研究中心、重大成果转化
- 4★（`clear`）：国家级项目、发明专利、出版著作/教材、SCI/EI 论文、服务世界 500 强多年、明确"多年经验"（≥10 年）且有标杆案例
- 3★（`vague`）：有讲师/培训/课程经验但无上述硬成果；■ 要点仅描述"擅长/经验丰富"无量化
- 2★（`missing`）：全字段无成果/经验表述

### ④ 社会荣誉与奖项（来源：职称/荣誉头衔、社会职务）
- 5★（`clear`）：两院院士、外籍院士（俄罗斯工程院等）、国家级人才计划（长江/杰青/万人）、国家级奖项（如 ISMS Practice Prize 类国际/国家奖）
- 4★（`clear`）：国家级荣誉/称号、国务院特殊津贴
- 3★（`clear`）：省部级荣誉/学者称号（如"岳麓学者"）、行业协会重要任职（副会长/委员）
- 2★（`vague`）：普通协会/学会会员、理事（无明确层级）
- 2★（`missing`）：全字段无荣誉表述

### ⑤ 职称、管理履历与行业地位（来源：职称/荣誉头衔、履职资历、社会职务、机构）
- 5★（`clear`）：教授/研究员/博士生导师 + 机构；或 CEO/总裁/董事长/创始人/院长（世界 500 强/央企/上市公司/头部企业）
- 4★（`clear`）：副教授/高工/副总裁/总监/CTO/合伙人 + 一定规模企业；或普通公司 CEO/创始人
- 3★（`vague`）：经理/主管/讲师/工程师/架构师（有任职但无高层级）
- 2★（`missing`）：全字段无职称/履历表述

## 四、综合得分计算

```
专业度 = (学历 + 资质 + 成果) / 3
影响力 = (荣誉 + 职称履历) / 2
综合得分 = 专业度 × 0.6 + 影响力 × 0.4
```
展示线 = 3★（综合 < 3★ 进观察库）。

## 五、证据（evidence）保留

每项评分须保留**触发该分的原始文本片段**（来自对应来源列/分段），供管理员在专家详情页查看"为什么是这个分"，也作为提取审计依据。

## 六、缺失 vs 模糊 的区分意义

- `missing`（未公开/空白）→ 取较低默认（学历 2★、其余 2★），代表"真没有信息"，是观察库与后续补录的主要对象。
- `vague`（有信息但笼统）→ 取中间档（通常 3★），代表"有但无法精确分级"，不应与缺失混同。
- 两者在 UI 与统计中分开展示，避免"填了模糊信息"被误判为"缺失"。
