专家评分规则 · 五星制

一、评分结构与计算

覆盖专业度、影响力 2 个维度，共 5 个评分项，并计算综合得分，具体设置如下：

维度 评分项 占比
专业度 ① 学历与学术背景 · ② 行业资质与认证 · ③ 专业成果与经验 60%（各项各 20%）
影响力 ④ 社会荣誉与奖项 · ⑤ 职称、管理履历与行业地位 40%（各项各 20%）

综合得分 = 专业度 × 60% + 影响力 × 40%，保留 1 位小数。

二、评分规则

评分项 1★ 2★ 3★ 4★ 5★
① 学历与学术背景 大专 / 中专及以下 普通本科（一般院校） 较好本科（211 / 双一流）或 普通硕士（授课型 / 一般院校） 名校硕士（985 / 双一流 / 海外知名）或 普通博士 博士 + 顶尖院校（清北 / C9 / QS 前 50 等）
② 行业资质与认证 无相关认证 培训 / 通用认证 行业厂商认证（华为 / 微软等）或 国家级执业资格（单一） 国家级执业 / 行业权威认证（多重领域） 国际权威认证（CFA / CPA / ACCA 等）或 多项国家级
③ 专业成果与经验 一般服务经验 / 仅公开演讲 参与级项目 / 普通论文 省级 / 行业级项目 · SCI/EI 论文 战略级 / 国家级项目 · 顶刊论文 标杆级（牵头国标行标 / 高被引 / 重大成果转化）
④ 社会荣誉与奖项 无荣誉 / 一般协会成员 地市级荣誉 / 国家级学会成员 省部级荣誉或称号 国家级荣誉或称号 顶尖人才（两院院士 / 国家级人才计划）
⑤ 职称、管理履历与行业地位 无职称 / 基层岗位 经理 / 高工 / 主管（普通企业） 副教授 / 总监 / VP / 合伙人（或同等级别 + 普通企业） 教授 / CEO / 创始人（行业百强 / 大厂） 教授 / CEO / 创始人（世界 500 强 / 央企 / 上市公司）

信息缺失（未填 / 未公开 / 无法核实）的评分项，默认 2★。

三、观察库与调分建议

观察库用于暂存综合评分低于 3⭐ 的专家，这些专家不会在前端对外展示。专家进入观察库后，系统会在半年、一年时分别提醒管理员复核；超过一年半仍未处理或仍未达标的专家将自动淘汰。

操作说明

1、原则：仅调整 5 个评分项的分值，且必须为整数分，调分幅度≤2；专业度、影响力、综合得分由系统按权重自动计算，不可直接编辑。

2、顺序：请先复核评分项（补录漏填信息、修正误评项），再结合实际情况判断是否需要调整某项评分。当前无法判断的，建议暂存在观察库，请记得在观察期内更新。

3、参考：如某位专家专业度、影响力在 2.7–2.9，无法进一步拿到 5 个评分项其他确认信息，可结合服务情况调整。若该专家与我司曾有合作，或明确知晓其服务项目/合作公司的评价（有背书），对满意度高、反馈好的专家，可重点看

① 合作方是否有关于专家的详细介绍、资质的佐证材料，授课过程中专家是否曾提到过自己的相关履历，优先补充、调整该专家的缺失/模糊信息，并调整对应评分项分值； ② 无补充信息，可适当调整 ③ 专业成果与经验的分值，服务也是经验的其中之一。

管理员操作建议（方向性，不规定具体分值）： 1. 成果项（③）和职称项（⑤）不弱，短板在资质（②）和荣誉（④）。若软著/专利中有较有影响力的（如已被引用或商业化），据实上调 ③。 2. 若该专家曾参与我司项目或合作：可据实上调 ④ 社会荣誉与奖项、⑤ 职称/管理履历，综合达展示线后自动在前端展示。 3. 若无合作记录且当前评分准确：维持现状，离展示线差距很小，后续任一维度补实信息即可达标。
