## 四、面向"未来问题"的补救措施建议

### 问题①：信息省略 ≠ 缺失 / 不专业 —— 怎么补救？

管理员上传时只保留"对部门有参考性"的信息，重复/过长/关联低的内容会被省略，但这会让专家在评分上"被压低"，与实际专业度不符。建议组合使用：

1. **观察库机制（已实现）**：综合 <3★ 进观察库，给管理员一张"待补强"清单。本轮乔锐杰、罗文正是靠补充信息越过 3★ 线出库的——观察库是发现"被信息不足误伤"专家的主要抓手。
2. **维度状态标记（status: missing / vague / clear）**：区分"真缺失"与"已有但展示不足"。对 `vague` 不急于压分、标记待补；对 `missing` 才按缺省 3★，且后台对管理员可见"该维度缺信息"提示，避免误判为"不专业"。
3. **合作记录反向背书**：已合作、满意度高的专家，其「合作满意度 / 项目反馈」应作为评分上调依据（规则已写：合作满意度高、反馈好可据实上调缺失/模糊项）。这是用"实际表现"补"公开信息不足"最直接的通道。
4. **公开渠道定期回填**：对 `vague/missing` 维度，在合作后或年度复盘时用官网/领英/论文库/新闻补充（本轮 35 位中大量"荣誉""资质"正是这样补回的）。
5. **专家信息定期维护提醒（新功能，规划中）**：因暂无法实时公网抓取，依赖管理员维护。设计：季度周期；谁添加谁负责（原添加人为主维护人，全员可补充）；提醒方式仅在管理员登录时弹出（账号未绑定企微 / 手机，无法主动推送），原添加人不可达（未登录 / 账号回收 / 找不到）则统一提醒主管理员；仅提示不强制。
6. **内部推荐人作可信度背书**：已收集的「内部推荐人」本身就是可靠性背书，评分/展示时应作为可信度参考，而非仅联系方式。

### 问题②："荣誉"绝大多数缺失 —— 怎么解决？

受限于已公开信息，荣誉维度天然稀疏。建议：

1. **公开渠道检索补录（本轮主做法）**：用大赛金奖、IEEE 奖项、年度人物、CCTV 创新奖、博鳌青年领袖等命名荣誉补录（任沁源、姚建明、刘华鹏、农洲、徐微、韦凯元、阿木等已落地）。建议沉淀一份「常见荣誉来源清单」（行业大赛 / 协会年会 / 媒体年度榜 / 政府奖）作为采集模板。
2. **合作方评价替代"荣誉"**：公开荣誉稀缺时，合作项目满意度、客户评价、复购可视为"行业认可"的等效证据，计入荣誉维度或单列。
3. **区分"真无"与"未公开"**：确无公开荣誉但合作好的，标记 `vague` 而非 `missing`；前端展示"荣誉信息受限"轻提示，避免误判。
4. **荣誉轻量化采集**：入库/复盘表单把"荣誉"拆成易勾选小项（是否获行业奖 / 媒体榜 / 协会任职），降低采集门槛。
5. **用"社会职务 / 行业地位"间接印证**：很多专家无"奖项"但有"协会秘书长 / 标准委员 / 评委"等职务，本身就是行业荣誉等价物——本轮已把大量社会职务补进对应段（刘伟华、周禹、黄洁、黄博、邵昶盛等）。
6. **长期：荣誉标签体系**：沉淀常见荣誉为标准标签，新专家入库时自动提示"是否拥有以下荣誉"，提升采集效率。
