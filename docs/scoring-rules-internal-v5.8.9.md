> **版本**：v5.8.9 ｜ **制定日期**：2026-08-03 ｜ **更新**：2026-08-04
> **定位**：评分规则的完整内部留底——详细赋分逻辑、计算规则、测算案例。用于检验赋分是否合理、测算结果是否有误。

## 一、总览

### 1.1 综合评分公式

```
综合分 = 专业度 × 60% + 影响力 × 40%

专业度下设 3 个子维度：学历(35%) / 行业资质(30%) / 专业成果(35%)
影响力下设 2 个子维度：社会荣誉(35%) / 职称行业地位(65%)
```

每个子维度独立打分 **0–10 分**，再按权重加权汇总。

### 1.2 三层评分结构（每子维度通用）

| 层 | 名称 | 作用 | 封顶 |
|----|------|------|------|
| 维度1 | **主锚点** | 取最高档定基础分（**不累计**，质量 > 数量） | — |
| 维度2 | **次要角度** | 院校实力 / 领域广度 / 持续性等微调 | **+0.5** |
| 维度3 | **额外加分** | 多学位 / 稀缺认证 / 高影响力成果等奖励分 | **+1.0**（动态封顶 = 10 − 主锚 − 维度2） |

> 动态封顶含义：维度3 的 +1.0 不是固定加到 10，而是「10 减去主锚与维度2 已用分数」后的余量。例如主锚 9.5 + 维度2 0.5 = 10.0 时，维度3 加分为 0。

### 1.3 全局规则

| 规则 | 值 | 说明 |
|------|----|------|
| 信息缺失默认分 | **5.0** | 五子维度一致（为空/未公开/模糊均视为缺失），不空置不占优 |
| 子维度硬封顶 | **10.0** | 主锚 + 维度2 + 维度3 求和后截断到 10 |
| 子维度软下限 | 0.0 | 求和后下限截断到 0 |
| 综合分 < 7 | **不进入观察库** | 只展示信息完整、实力明确的专家 |
| 四舍五入 | 保留 1 位小数 | 每层计算结果均四舍五入至 1 位小数 |
| 成就类 1–3 档 | **待定** | 资质/成果/荣誉/职称的低分档位：方案X（问题地档全 1–10 覆盖）vs 方案Y（地面 4）未拍板 |

## 三、计算规则（纯逻辑，不含代码）

### 3.1 计算步骤

```
Step 1 — 取子维度分值：
  若该子维度有录入值 → 使用录入值
  若缺失（空/未公开/模糊）→ 统一取 5.0
  结果截断到 [0, 10]（超出封顶或低于零均修正）

Step 2 — 加权求大维度分：
  专业度 = 学历分×35% + 资质分×30% + 成果分×35%
  影响力 = 荣誉分×35% + 职称分×65%

Step 3 — 加权求综合分：
  综合分 = 专业度×60% + 影响力×40%

Step 4 — 四舍五入：
  每步结果保留 1 位小数
```

### 3.2 关键规则说明

- **缺失不占优也不塌陷**：任一子维度缺失统一给 5.0（中等偏下），不会因漏填而拉低整体，也不会让信息不足者占便宜。
- **权重作用于子维度层**：先算「子分数 × 子维度权重」再求和得大维度分，不是先平均再加权。
- **主锚点不累计**：同一子维度的维度1只取最高档（如同时有博士和硕士，只取博士；同时有A0和A1资质，只取A0）。
- **动态封顶**：维度3的可用空间 = 10 − 主锚分 − 维度2分。若前两层已占满 10 分，维度3无法再加。
- **手动可覆盖**：自动评分仅供参考，管理员可在后台手动调整任意子维度分值，调整后自动重新计算综合分。

## 四、五个子维度详细赋分细则

### 4.1 ① 学历与学术背景（专业度 · 权重 35%）

**类型**：matrix（学历层次 × 院校实力），取最高学历

#### 维度1 主锚 — 学历基线 × 院校偏移

| 学历层次 | 基线分 | 说明 |
|:--------:|:------:|------|
| 博士 | 9.5 | 含全日制博士、在职博士（需核实培养单位） |
| 硕士 | 8.5 | 含全日制硕士、MBA/MPA 等 |
| 本科 | 8.0 | 含统招本科、自考本科 |
| 专升本 | 5.0 | 上限锁定 5.0（保证统招本科始终更高） |
| 专科 | 4.0 | 优质专科 4.0 / 普通 3.5 / 成人自考 3.0 |
| 高中及以下 | 2.5 | 高中/中专 2.5 / 初中 2.0 / 小学 1.0 |

**院校 tier 偏移量**：

| 院校 tier | 定义 | 偏移 |
|:---------:|------|:----:|
| T0 | 清北 / QS·THE·ARWU 前 50 / 央企研究院所 | **+0.0**（基准） |
| T1 | 985 工程 / 双一流高校 | −0.5 |
| T2 | 211 工程 / 双一流学科 | −1.0 |
| T3 | 普通本科院校 | −1.5 |
| T4 | 其他 / 民办 / 无法核实 | −2.5 |

> 最终主锚 = MAX(基线 + 偏移, 该学历保底分)。例：博士 T4 = 9.5 − 2.5 = 7.0；专升本 T0 = 5.0（上限锁死）。

#### 维度2 院系权威微调（封顶 +0.5）

| 条件 | 加分 |
|------|:----:|
| 所在院系为国家 A+ 学科 / 双一流学科 | +0.3 |
| 继续教育学院 / 远程教育 / 非全日制项目 | −0.3 |
| 其他情况 | 0 |

#### 维度3 学位权威性加分（动态封顶）

| 条件 | 加分 |
|------|:----:|
| 第二有效学位（院校层级 ≥ 第一学位） | +0.3 |
| 第二学位为跨学科 / 复合型（如 工学+MBA） | +0.3 |
| 第三有效学位（同上条件） | +0.2 |

#### 特殊规则

- **博士后不计入学历**，归入「④专业成果」的科研经历维度3（+0.5）
- **水硕 / 在线无门槛硕士**：T4 院校再 −0.5（≈ 5.5–6.0）
- **自考本科** = 本科 T4 = 6.0（与统招本科 T4 同等待遇）
- **多学历取最高**：如同时有博士和两个硕士，只取博士为主锚，其余走维度3加分

### 4.2 ② 行业资质与认证（专业度 · 权重 30%）

**类型**：tier（按颁发主体层级），取最高一项

#### 维度1 主锚 — 认证层级（5 档 + 缺失）

| 层级 | 基线分 | 颁发主体判定 | 典型示例 | 边界与降档情形 |
|:----:|:------:|------------|---------|--------------|
| **A0** 国际权威认证 | **9.0** | 国际公认专业组织 / 国家法定统考 | CFA 三级通过、CPA 持证、ACCA 会员、注册建筑师 | 单一机构培训结业**不算** A0 |
| A1 国家级执业 / 行业权威 | 8.0 | 国家部委颁发或行业协会全国统一考试 | 注册会计师(国内)、法律职业资格、执业医师 | 省/市级协会自行认证 → 降一档 |
| A2 行业厂商认证 | 6.0 | 企业 / 厂商自行考核颁发 | 华为 HCIE、微软 / 阿里云高级认证、PMP | 厂商认证须为高级；初级 → A3 |
| A3 培训 / 通用认证 | 4.0 | 培训机构、入门级、在线刷题可得 | 一般培训证书、在线微专业 | 纯刷题型认证水分大，可记 A3 或不计 |
| 缺失 | 5.0 | 无任何认证信息 | — | 不空置、不占优 |

> 主锚 = 取最高一档（质量 > 数量）。持有 3 个 A0 仍按 A0 = 9.0 计（广度归维度2）。

#### 维度2 跨领域广度（封顶 +0.5）

| 条件 | 加分 |
|------|:----:|
| ≥ 2 个不相关领域有效认证（如 CFA + PMP） | +0.3 |
| ≥ 3 个不相关领域有效认证 | +0.5 |

#### 维度3 稀缺性强相关加分（动态封顶）

| 条件 | 加分 |
|------|:----:|
| 同时持有双 A0 或 A0+A1 级认证 | +0.5 |
| PMP / PgMP 等国际项目管理认证 | +0.5 |
| 与专家主领域强相关且市场稀缺 | +0.5 |

#### 特殊规则

- **同机构多级只取最高**：如华为 HCIA / HCIP / HCIE，只取 HCIE（A2）；不累计为更高层级。
- **自考 / 成人教育类资格**：等同于对应层级，但 −0.5（如自考本科 + 成考资格 ≈ A2 − 0.5）。
- **过期认证**：原则上不计入，除非持证人完成持续教育保持有效。
- **强相关优先**：与专家主领域无关的高层级认证（如程序员持 CPA）仅计入主锚，不享受维度3强相关加分。
- **水分识别**：无明确评审过程、付费即可获得的「榜单 / 会员」类认证，不计入或按 A3 处理。

### 4.3 ③ 专业成果与经验（专业度 · 权重 35%）

**类型**：dual-path（学术路径 vs 企业路径，**取高不累计**）

#### 维度1 主锚 — 双路径取高（每条路径独立 5 档 + 缺失）

| 层级 | 学术路径判定（第一/通讯作者优先） | 企业路径判定 | 分值 |
|:----:|-------------------------------|------------|:----:|
| **A0/B0** 顶级 | 顶刊(N/S/C)及子刊；近 5 年 ESI 高被引 Top 1%；独著学术专著(ISBN)；授权发明专利(第一发明人 ≥ 2 项) | 主持国家级重大项目(科技部/发改委立项，负责人/技术总监)；产品用户 > 1000 万 | **9.0** |
| A1/B1 高级 | SCI/EI(JCR Q1/Q2)；核心(北大核心/CSSCI)；参与国家级课题(前 5) | 主持省部级项目；产品用户 > 100 万；知名企业架构师及以上 | 8.0 |
| A2/B2 中级 | 普通期刊论文；省级课题参与；会议论文 | 核心成员参与省部级及以上项目 | 6.0 |
| A3/B3 基础 | 仅公开演讲/分享（无正式出版物） | 一般工作产出(内部报告/日常交付) | 4.0 |
| 缺失 | — | — | 5.0 |

> 主锚 = 分别算出学术分与企业分，**取较高的一条**作为主锚。另一条路的突出表现可酌情纳入维度3。

#### 维度2 持续性与影响力（封顶 +0.5）

| 条件 | 加分 |
|------|:----:|
| H-index ≥ 15 **或** 授课/分享 ≥ 50 场 | +0.3 |
| H-index ≥ 25 **或** 授课/分享 ≥ 100 场 | +0.5 |

#### 维度3 高影响力成果加分（动态封顶）

| 条件 | 加分 |
|------|:----:|
| 顶刊（Nature/Science/Cell 正刊）第一/通讯作者论文 | +0.5 |
| 牵头制定国家标准 / 行业标准（主要起草人） | +0.5 |
| **正规博士后科研经历**（全职，≥ 1 年，流动站/工作站） | +0.5 |

#### 特殊规则

- **学术 vs 企业取高**：不累计，避免双重加权；两条路径分别判定后再取高。
- **博士后归此**：博士后经历不是学历，是科研经历，计入本子维度维度3（+0.5），不重复计算学历分。
- **专利折算**：实用新型 / 外观设计专利按 A2 计；发明专利按 A0/A1 计（看发明人排名）。
- **产品规模口径**：用户数为去重月活(MAU)；内部系统、未上线项目不计规模分。
- **署名权重**：非第一 / 非通讯作者的论文，降一档计（如二作 SCI → A2）；参与课题非前 5 名，降一档。

### 4.4 ④ 社会荣誉与奖项（影响力 · 权重 35%）

**类型**：tier（按行政级别 / 颁发方权威性），取最高一项

#### 维度1 主锚 — 荣誉层级（5 档 + 缺失）

| 层级 | 基线分 | 颁发主体判定 | 典型示例 | 边界与降档情形 |
|:----:|:------:|------------|---------|--------------|
| **H0** 国家级 | **9.0** | 国务院 / 国家部委颁发 | 国家科学技术奖、全国五一劳动奖章、国务院政府特殊津贴、国家级教学名师 | 部委下属司局颁发 → 视 H1 |
| H1 省部级 | 7.5 | 省/自治区/直辖市政府或部委下属司局 | 省科技进步奖、省级人才计划(千人/万人) | 地市政府颁发 → 视 H2 |
| H2 地市级 / 国家级学会 | 6.0 | 地市政府；中国科协一级学会 / 全国性行业协会 | 市级科技奖、一级学会奖、权威行业榜单(福布斯/胡润) | 付费无评审榜单 → H3 或不计 |
| H3 县级 / 一般协会 | 4.0 | 县级政府；一般性协会 / 商会 / 媒体 | 县级奖励、普通协会奖 | 水分较大榜单可不计 |
| 缺失 | 5.0 | 无任何荣誉信息 | — | 不空置 |

> 主锚 = 取最高一项荣誉（数量不累计）。同级别多项荣誉的广度加成见维度2。

#### 维度2 同级别广度（封顶 +0.5）

| 条件 | 加分 |
|------|:----:|
| 同级别（如同为 H1）荣誉 ≥ 2 项 | +0.3 |
| 同级别荣誉 ≥ 3 项 | +0.5 |

#### 维度3 顶尖人才标识（动态封顶）

| 条件 | 加分 |
|------|:----:|
| **两院院士**（中国科学院/工程院院士） | **+1.0** |
| 国家级人才计划入选（万人/千人/杰青/长江等） | +0.5 |
| 国际权威榜单入选（如 Thomson Reuters Highly Cited Researcher） | +0.5 |

> 院士 +1.0 是全体系唯一突破 +1.0 封顶的单项加分（可使本子维度达到理论最大 10.0 甚至略超后再被硬封顶截回 10.0）。

#### 特殊规则

- **榜单权威性定档**：福布斯 / 胡润等权威榜单 ≈ H2；付费上榜、无评审过程 ≈ 不计入或 H3。
- **人才计划层级**：国家级计划(院士/杰青/长江) → 维度3 +0.5~1.0；省级计划计 H1。
- **集体荣誉**：以团队名义获得的奖项，个人贡献须可辨识(排名/证书署名)方可计入，否则降一档。
- **历史荣誉**：早年获得的荣誉仍有效；若已无持续相关性，权重可酌情下调（不影响封顶，仅影响主锚判定口径）。

### 4.5 ⑤ 职称、管理履历与行业地位（影响力 · 权重 65%）

**类型**：matrix（职级 J × 机构 C）

#### 维度1 主锚 — J×C 矩阵

已在 [§2.5](#25-职称--机构-矩阵子维度⑤) 完整列出。补充判定标准：

**职级 J 判定**：

| 职级 | 对应身份 | 基线分 |
|:----:|---------|:------:|
| **J0** | 教授/研究员/正高级工程师；院士；首席科学家/首席架构师；CEO/总裁/创始人/董事长 | 9.5 |
| J1 | 副教授/副研究员/高级工程师；总监/VP/合伙人；部门负责人 | 8.5 |
| J2 | 讲师/工程师/经理/主管/资深专员 | 7.0 |
| J3 | 无职称/助理/基层员工/实习生 | 5.5 |

**机构 C 判定**：

| 机构 tier | 定义 | 偏移 |
|:---------:|------|:----:|
| **C0** | 世界 500 强；央企总部/重要子公司；A股上市公司（市值 top 200）；国家级科研院所 | +0.0 |
| C1 | 行业百强企业；大厂（字节/腾讯/阿里/美团等）；独角兽；省级国企 | −0.5 |
| C2 | 普通中小企业；初创公司；外企普通岗位；自由职业 | −1.0 |

> 特殊：初创公司界定为 **A 轮前**（A 轮及以后按估值/规模归入 C1 或 C2）。

#### 维度2 履历厚度（封顶 +0.5）

| 条件 | 加分 |
|------|:----:|
| 从业年限 ≥ 10 年 | +0.3 |
| 从业年限 ≥ 15 年 **或** 有跨行业（≥ 2 个不相关领域）从业经历 | +0.5 |

#### 维度3 标志性职位与变革贡献（动态封顶）

| 条件 | 加分 |
|------|:----:|
| 国家标准化委员会委/一级学会常务理事/早期创始团队核心成员（A 轮前加入） | +0.5 |
| **主导过企业级变革**（转型/重组/数字化等，有可验证成果） | +0.3 |

#### 特殊规则

- **初创公司界定**：A 轮前视为 C2；A 轮及以后按估值/规模归入 C1 或 C2。
- **技术职级 vs 行政职级交叉**：如「高级工程师」技术职级按 J2，但若任总工/技术总监则按 J1；以实际权责定档。
- **自由职业 / 独立顾问**：无机构归属 → C2；若该专家在某头部企业任外部首席顾问且可验证，可按 C1。
- **退休返聘 / 兼职**：以实际承担职责定档，不按最高历史职务虚高计。
- **学术与产业双跨**：同时有教授职称(J0)与企业任职(C0)，取矩阵高位（9.5）。
- **空壳职位**：名义 CEO 但无实际管理权限（如家族企业挂名）→ 按 J2 计。

## 五、测算案例（含逐步验算）

> 以下案例按上述计算规则手算，用于检验评分逻辑是否自洽、边界条件是否正确处理。

### 案例 A — 全缺失（基准校验）

**场景**：新录入专家，所有字段均为空。

| 子维度 | 状态 | 得分 |
|:------:|:----:|:----:|
| ① 学历 | 缺失 | **5.0** |
| ② 资质 | 缺失 | **5.0** |
| ③ 成果 | 缺失 | **5.0** |
| ④ 荣誉 | 缺失 | **5.0** |
| ⑤ 职称 | 缺失 | **5.0** |

**逐步计算**：
```
专业度 = 5.0×35% + 5.0×30% + 5.0×35% = 1.75 + 1.50 + 1.75 = 5.0
影响力 = 5.0×35% + 5.0×65% = 1.75 + 3.25 = 5.0
综合   = 5.0×60% + 5.0×40% = 3.00 + 2.00 = 5.0
```
**结果：综合 = 5.0** ✅ 缺失不占优，< 7 不进入观察库。

### 案例 B — 顶级专家（封顶校验）

**场景**：各维度均接近满分，测试硬封顶 10 是否正确触发。

| 子维度 | 主锚 | 维度2 | 维度3 | 合计（截断后） |
|:------:|:----:|:-----:|:-----:|:-------------:|
| ① 学历 | 博士 T0 = 9.5 | A+学科 +0.3 | 第二学位+跨学科 +0.6 | 10.4 → **10.0** |
| ② 资质 | A0 = 9.0 | — | 双A0+PMP +1.0 | 10.0 → **10.0** |
| ③ 成果 | A0 = 9.0 | H≥25 +0.5 | 高被引+0.5 | 10.0 → **10.0** |
| ④ 荣誉 | H0 = 9.0 | ≥3项 +0.5 | 院士 +1.0 | 10.5 → **10.0** |
| ⑤ 职称 | J0×C0 = 9.5 | 从业15年+0.5 | 早期创始+0.5 | 10.5 → **10.0** |

**逐步计算**：
```
专业度 = 10.0×35% + 10.0×30% + 10.0×35% = 3.50 + 3.00 + 3.50 = 10.0
影响力 = 10.0×35% + 10.0×65% = 3.50 + 6.50 = 10.0
综合   = 10.0×60% + 10.0×40 = 6.00 + 4.00 = 10.0
```
**结果：综合 = 10.0** ✅ 所有子维度均触发硬封顶 10。

### 案例 C — 混合缺失（临界校验）

**场景**：部分维度有数据、部分缺失，测试综合分 < 7 的临界行为。

| 子维度 | 主锚 | 维度2/3 | 得分 |
|:------:|:----:|:-------:|:----:|
| ① 学历 | 硕士 T1 = 8.0 | 无 | **8.0** |
| ② 资质 | 缺失 | — | **5.0** |
| ③ 成果 | A2 = 6.0 | 持续性 +0.3 | **6.3** |
| ④ 荣誉 | 缺失 | — | **5.0** |
| ⑤ 职称 | J1×C1 = 8.0 | 从业10年+0.3 | **8.3** |

**逐步计算**：
```
专业度 = 8.0×0.35 + 5.0×0.30 + 6.3×0.35 = 2.80 + 1.50 + 2.205 = 6.505 → 6.5
影响力 = 5.0×0.35 + 8.3×0.65 = 1.75 + 5.395 = 7.145 → 7.1
综合   = 6.5×0.60 + 7.1×0.40 = 3.90 + 2.84 = 6.74 → 6.7
```
**结果：综合 = 6.7** ⚠️ < 7，不进入观察库。符合设计预期——信息不完整的专家不应展示。

### 案例 D — 中等水平（典型校验）

**场景**：大多数专家的常见画像——有学历有职称，资质和成果中等，无特殊荣誉。

| 子维度 | 主锚 | 维度2/3 | 得分 |
|:------:|:----:|:-------:|:----:|
| ① 学历 | 本科 T2 = 7.0 | 普通 | **7.0** |
| ② 资质 | A2 = 6.0 | 2领域+0.3 | **6.3** |
| ③ 成果 | B1 = 8.0 | 授课30场+0.3 | **8.3** |
| ④ 荣誉 | H2 = 6.0 | 无 | **6.0** |
| ⑤ 职称 | J2×C1 = 6.5 | 从业12年+0.3 | **6.8** |

**逐步计算**：
```
专业度 = 7.0×0.35 + 6.3×0.30 + 8.3×0.35 = 2.45 + 1.89 + 2.905 = 7.245 → 7.2
影响力 = 6.0×0.35 + 6.8×0.65 = 2.10 + 4.42 = 6.52 → 6.5
综合   = 7.2×0.60 + 6.5×0.40 = 4.32 + 2.60 = 6.92 → 6.9
```
**结果：综合 = 6.9** ⚠️ < 7，不进入观察库。这类"中等偏上但信息不全"的专家占多数，需要补齐资质或成果才能达标。
