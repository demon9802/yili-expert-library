# 专家评分规则 · 五星制

## 一、评分结构与计算

覆盖专业度、影响力 2 个维度，共 5 个评分项。每个评分项各占 **20%**，最终综合得分即 5 个评分项的算术平均。

| 维度 | 评分项 | 计算说明 |
|---|---|---|
| 专业度 | ① 学历与学术背景 · ② 行业资质与认证 · ③ 专业成果与经验 | 专业度 =（① + ② + ③）÷ 3 |
| 影响力 | ④ 社会荣誉与奖项 · ⑤ 职称、管理履历与行业地位 | 影响力 =（④ + ⑤）÷ 2 |
| **综合得分** | ①②③④⑤ 五项合计 | **综合得分 =（① + ② + ③ + ④ + ⑤）÷ 5 = 专业度 × 60% + 影响力 × 40%**，保留 1 位小数 |

> 说明：虽然写法上同时出现了“每个评分项 20%”和“专业度 60% / 影响力 40%”，但二者数学等价，计算结果一致，不存在漏洞。按 5 项各 20% 理解最直接：综合得分就是五项打分的平均值。

## 二、评分规则

| 评分项 | 1★ | 2★ | 3★ | 4★ | 5★ |
|---|---|---|---|---|---|
| ① 学历与学术背景 | 大专 / 中专及以下 | 普通本科（一般院校） | 较好本科（211 / 双一流）或 普通硕士（授课型 / 一般院校） | 名校硕士（985 / 双一流 / 海外知名）或 普通博士 | 博士 + 顶尖院校（清北 / C9 / QS 前 50 等） |
| ② 行业资质与认证 | 无相关认证 | 培训 / 通用认证 | 行业厂商认证（华为 / 微软等）或 国家级执业资格（单一） | 国家级执业 / 行业权威认证（多重领域） | 国际权威认证（CFA / CPA / ACCA 等）或 多项国家级 |
| ③ 专业成果与经验 | 一般服务经验 / 仅公开演讲 | 参与级项目 / 普通论文 | 省级 / 行业级项目 · SCI/EI 论文 | 战略级 / 国家级项目 · 顶刊论文 | 标杆级（牵头国标行标 / 高被引 / 重大成果转化） |
| ④ 社会荣誉与奖项 | 无荣誉 / 一般协会成员 | 地市级荣誉 / 国家级学会成员 | 省部级荣誉或称号 | 国家级荣誉或称号 | 顶尖人才（两院院士 / 国家级人才计划） |
| ⑤ 职称、管理履历与行业地位 | 无职称 / 基层岗位 | 经理 / 高工 / 主管（普通企业） | 副教授 / 总监 / VP / 合伙人（或同等级别 + 普通企业） | 教授 / CEO / 创始人（行业百强 / 大厂） | 教授 / CEO / 创始人（世界 500 强 / 央企 / 上市公司） |

信息缺失（未填 / 未公开 / 无法核实）的评分项，默认 2★。

## 三、观察库与调分建议

观察库用于暂存综合评分低于 3⭐ 的专家，这些专家不会在前端对外展示。

**观察期与提醒机制**

- 专家进入观察库后，系统默认设置 **18 个月**观察期；
- 入库满 **6 个月**、满 **12 个月** 时，系统向负责该专家的管理员推送维护提醒：
  - 优先提醒**该专家的创建者**（录入人）；
  - 若创建者为子管理员且账号已被回收/删除，则提醒升级至**主管理员**；
  - 主管理员始终可见全部待维护专家的汇总提示；
- 观察期满（18 个月）仍未达标且未被延后/处理，系统自动淘汰（留痕，数据保留可恢复）。

**延后观察**

- 在临近淘汰节点，管理员可点击“延后观察”，系统将当前淘汰截止日**顺延 6 个月**；
- 延后观察**不会重新计算 18 个月观察期**，也不会重置已入库时间，仅推迟淘汰节点；
- 每次延后必须填写意见并留痕。

**操作说明**

1、**原则**：仅调整 5 个评分项的分值，且必须为整数分；专业度、影响力、综合得分由系统按权重自动计算，不可直接编辑。

2、**操作流程**：针对单个专家，先在卡片内连续修改 5 个子维度分值，确认无误后点击“确认调分”并填写操作意见，系统一次性记录本次调整；如需淘汰，则点击“淘汰”并填写意见。每个专家的每次调分或淘汰都必须留痕。

3、**顺序**：请先复核评分项（补录漏填信息、修正误评项），再结合实际情况判断是否需要调整某项评分。当前无法判断的，建议暂存在观察库，请记得在观察期内更新。
