# 专家评分规则 · 五星制

## 一、评分结构与计算

覆盖专业度、影响力 2 个维度，共 5 个评分项，并计算综合得分，具体设置如下：

| 维度 | 评分项 | 占比 | 综合得分 |
|---|---|---|---|
| 专业度 | ① 学历与学术背景 · ② 行业资质与认证 · ③ 专业成果与经验 | 60%（各项各 20%） | 专业度 × 60% + 影响力 × 40%，保留 1 位小数 |
| 影响力 | ④ 社会荣誉与奖项 · ⑤ 职称、管理履历与行业地位 | 40%（各项各 20%） | |

---

## 二、评分规则

| 评分项 | 1★ | 2★ | 3★ | 4★ | 5★ |
|---|---|---|---|---|---|
| ① 学历与学术背景 | 大专 / 中专及以下 | 普通本科（一般院校） | 较好本科（211 / 双一流）或 普通硕士（授课型 / 一般院校） | 名校硕士（985 / 双一流 / 海外知名）或 普通博士 | 博士 + 顶尖院校（清北 / C9 / QS 前 50 等） |
| ② 行业资质与认证 | 无相关认证 | 培训 / 通用认证 | 行业厂商认证（华为 / 微软等）或 国家级执业资格（单一） | 国家级执业 / 行业权威认证（多重领域） | 国际权威认证（CFA / CPA / ACCA 等）或 多顶国家级 |
| ③ 专业成果与经验 | 一般服务经验 / 仅公开演讲 | 参与级项目 / 普通论文 | 省级 / 行业级项目 · SCI/EI 论文 | 战略级 / 国家级项目 · 顶刊论文 | 标杆级（牵头国标行标 / 高被引 / 重大成果转化） |
| ④ 社会荣誉与奖项 | 无荣誉 / 一般协会成员 | 地市级荣誉 / 国家级学会成员 | 省部级荣誉或称号 | 国家级荣誉或称号 | 顶尖人才（两院院士 / 国家级人才计划） |
| ⑤ 职称、管理履历与行业地位 | 无职称 / 基层岗位 | 经理 / 高工 / 主管（普通企业） | 副教授 / 总监 / VP / 合伙人（或同等级别 + 普通企业） | 教授 / CEO / 创始人（行业百强 / 大厂） | 教授 / CEO / 创始人（世界 500 强 / 央企 / 上市公司） |

信息缺失（未填 / 未公开 / 无法核实）的评分项，默认 3★。

---

## 三、观察库与调分建议

**进入观察库**：综合得分 < 3★（不含 3★），不在前端对外展示。

**操作顺序**：先复核评分项（补录漏填信息、修正误评项）→ 再结合实际情况判断是否需要调整某项评分项。

**调分原则**：仅调整 5 个评分项，且为整数分，调分幅度≤2；专业度、影响力、综合得分由系统按权重自动计算平均值，不可直接编辑。下方为方向性参考，请根据实际情况进行判断或专家信息补充：

过往服务经历、与我司已合作项目已在专家详情页展示，不作为打分项，由管理员根据实际情况判断，方向性参考如下：

| 服务情况 | 参考方向（看什么 / 调哪个评分项） |
|---|---|
| 与我司有合作且满意度高 | 重点看 ④ 社会荣誉与奖项、⑤ 职称 / 管理履历：若合作中体现出行业地位或客户认可，可据实上调对应评分项；综合达展示线后自动在前端展示 |
| 与我司有合作但反馈一般 | 维持现状，留在观察库、暂不展示，可根据后续新的合作评价或补足某项评分项信息后，再重新评估该专家能力 |
| 有服务记录，无我司合作 | 维持现状，待补充缺失或模糊的信息后再判断；如专业度、影响力在 2.7–2.9 时，可比照评分规则的标准进行复核 |
| 合作过但不合适 | 评估后直接从专家库移除 |

## 四、测算

| 情形 | ① | ② | ③ | ④ | ⑤ | 综合得分 | 是否进观察库 |
|---|---|---|---|---|---|---|---|
