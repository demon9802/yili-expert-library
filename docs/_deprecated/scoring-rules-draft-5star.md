# 评分规则简化版（候选 A）· 五星查表制

> **状态**：待评审草案，未部署。与「候选 B（10 分查表制）」对比后定稿。
> **设计目标**：赋分 = 查表，不计算；去掉所有微调层；术语通俗；五个子维度等权。

---

## 一、结构（与现行一致，仅权重拍平）

- 两个一级维度：**专业度（60%）** / **影响力（40%）** —— 保留
- 五个评分项，**每个对综合分贡献均为 20%**：
  - 专业度内三项各占专业的 1/3（≈ 20% 综合）
  - 影响力内两项各占影响力的 1/2（= 20% 综合）

## 二、星 → 分换算

```
★ = 0      ★★ = 2.5      ★★★ = 5.0      ★★★★ = 7.5      ★★★★★ = 10
```
- **信息缺失 → 默认 ★★★ = 5.0**（中性值，与现行缺失默认分一致）
- 展示为五星；缺失项显示「未填」灰星

## 三、计算公式（无歧义版）

```
专业度 = (学历星分 + 资质星分 + 成果星分) / 3
影响力 = (荣誉星分 + 职称星分) / 2
综合分 = 专业度 × 60% + 影响力 × 40%
```
- 综合分 < 7 不进入观察库
- 子维度无封顶概念（五星天然在 [0,10]）

## 五、术语替换（去专业化）

| 旧词 | 新词 | 说明 |
|---|---|---|
| 主锚点 | 主标准 | 直接说"对应哪一行" |
| 维度 / 子维度 | 评分项 / 一级维度 | 专业度、影响力叫一级维度；五项叫评分项 |
| 维度2 / 维度3 加分 | （删除） | 五星制无此概念 |
| 硬封顶 / 封顶 | 上限 | 五星天然有上限 |
| 缺失默认分 | 未填默认分 | 更直白 |

## 六、后台「权重」字段表达（消除歧义）

- **一级维度「权重」** → 改名为 **「一级维度占比」**，备注：`专业度、影响力对综合分的占比（当前 60% / 40%）`
- **评分项「权重」** → 改名为 **「组内占比」**，备注：`该项在所属一级维度内的占比；五个评分项对综合分的实际贡献均为 20%`
- 因等权，**组内占比可设为自动只读**（专业度内三项各 33.3%、影响力内两项各 50%），后台不手填，从源头消除歧义

## 七、优点 / 待确认

**优点**
- 赋分 = 查表，零计算，演示/汇报一句话讲清
- 五星直观，前端展示友好（尤其手机端）
- 彻底去掉 +0.5 / +1.0 微调层，规则最薄

**待确认**
- 精度仅 5 档（每档 2.5 分），对细微差距不敏感
- 院校/机构 tier（如清北 vs 普通）被合并进单行，粒度损失
- 缺失默认 ★★★=5.0，展示用灰星还是半星需定
